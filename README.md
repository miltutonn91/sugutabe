# 宅配野菜 LP（スクール課題）

## プロジェクトの概要

架空のオーガニック野菜の宅配サービス「スグ食べ」を題材に、スクール課題として制作したLPです。

食材の安全性や品質に関心のある方に向けて、サービスの特徴や生産者の情報、お試しセットの内容を紹介し、安心して利用を検討できるよう情報を整理しています。

ファーストビューからサービスの特徴、品質へのこだわり、利用者の声、申し込み案内へとつながる構成にし、サービスへの理解を深めながら検討できるLPを目指しました。

## デザインについて

新鮮な野菜の魅力と、安心して利用できるサービスであることが伝わるよう、自然を感じられる配色や写真、親しみやすい装飾を取り入れてデザインしました。

情報量の多いLPでも読み進めやすく、申し込み導線へ自然につながるよう、情報の見せ方やCTAの配置を意識しています。

## 開発環境構築方法

### 1. リポジトリをクローン

```bash
git clone https://github.com/miltutonn91/sugutabe.git
```

### 2. ディレクトリへ移動

```bash
cd sugutabe
```

### 3. ブラウザで確認

`index.html` をブラウザで開くことで、ローカル環境で表示確認できます。

本サイトは静的なHTML / CSS / JavaScriptで制作しているため、パッケージのインストールやビルド作業は不要です。
