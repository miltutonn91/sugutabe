# 宅配野菜 LP（スクール課題）

## プロジェクトの概要

架空のオーガニック野菜の宅配サービス「スグ食べ」を題材にしたLPです。

新鮮さや安心感が直感的に伝わるよう、ファーストビューからサービス紹介、品質へのこだわり、利用者の声、申し込み導線までを整理して制作しました。

ユーザーがサービス内容を理解し、申し込みまで進みやすいよう、情報の順番やCTAの配置を意識しています。

## 開発環境構築方法

### 1. リポジトリをクローン

```bash
git clone https://github.com/miltutonn91/sugutabe.git
```

### 2. ディレクトリへ移動

```bash
cd sugutabe
```

### 3. ブラウザで確認

`index.html` をブラウザで開くことで、ローカル環境で表示確認できます。

本サイトは静的なHTML / CSS / JavaScriptで制作しているため、パッケージのインストールやビルド作業は不要です。
